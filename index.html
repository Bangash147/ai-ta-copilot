About this prototype

Working prototype

This page. Runs in any browser with no install. Sample mode replays pre-generated outputs; live mode sends prompts to Claude through the Anthropic API with your own key. Synthetic data only.

Prompt-based workflow

Every step has a “Copy prompt” button. The same prompts work in Claude or ChatGPT chat — the recruiter pastes inputs and reviews outputs. No integration needed.

Production automation

Not built. A production version would integrate with the ATS (e.g., Ashby) through approved APIs, with access control, logging, retention rules, a privacy review and bias monitoring.

Design principles

  • AI drafts; people approve, edit and decide — enforced by checkpoints in the flow.
  • The screening prompt forbids scores, rankings, and inferences about protected characteristics; it must quote evidence or say “No evidence found”.
  • Personal data (names, emails, phones, links) is redacted before any AI call.
  • No scraping and no platform integrations; sourcing strings are run by the recruiter on each platform under its terms.
  • All candidate profiles, the job brief and dashboard data are fictional.

Limitations

  • AI can misread or invent details — every evidence line must be verified against the CV.
  • Keyword evidence under-represents non-traditional candidates; the recruiter conversation remains essential.
  • Live mode depends on your API key, network and model availability.
